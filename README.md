# IT Support Computer Requirements Evaluation

This project evaluates the hardware, software, and networking requirements needed for a 4K video editing workstation. The goal was to determine the appropriate technology needed for an employee to edit high-resolution video efficiently, securely, and reliably.

## Skills Demonstrated

- Hardware requirements analysis
- Software requirements analysis
- Networking requirements analysis
- Storage and backup planning
- System compatibility considerations
- IT support documentation

- ## Project Summary

For this project, I evaluated the technology needs of a video editor responsible for creating and editing 4K content. I selected hardware, software, storage, and networking solutions based on performance, reliability, compatibility, and security.

The completed evaluation includes recommendations for processing power, memory, graphics, storage, editing software, network connectivity, backups, and secure remote access.

## What I Learned

This project helped me better understand how hardware, software, storage, and networking choices work together to support an employee's job requirements.

I also learned how important it is to consider performance, compatibility, reliability, security, and data backup when recommending a computer setup for a specific role.
